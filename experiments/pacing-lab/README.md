# Pacing lab

- Hypothesis: progressive disclosure can reach Publication in a configurable 60–120 active-equivalent minute band without dead intervals.
- Parameters: event timing bands and maximum decision/progress/reveal gaps.
- Output: `pacing-results.json` and `PACING_ANALYSIS.md`.
- Conclusion: the five-band design-density comparison favors 60–90 minutes with 90–120 close; the full 60–120 band is implementation-ready only as provisional configuration, not locked balance.
