# Frontend

## Result

Select Preact + TypeScript + Vite with a framework-independent engine.

## Method

Deterministic model `phase0-design-lab/1.0.0`; no randomness or timestamp enters the output. Inputs, candidate metrics, criteria weights, rankings, and sensitivity results are preserved in [`frontend-stack-results.json`](./data/frontend-stack-results.json). Scores are explained heuristics, while numerical allocation and offline outputs are enumerated calculations.

## Limitation

Bundle figures must be measured once the Phase 1 scaffold exists. This evidence narrows implementation choices; it does not measure fun.
