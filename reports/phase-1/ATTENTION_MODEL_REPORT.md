# Attention model report

Attention is an integer allocation with starting capacity 3 and maximum 4. Activities use `base × allocation^exponent` with exponent 0.8; projects remain linear in a dedicated slot. The marginal table covers exponents 0.65, 0.7, 0.75, 0.8, 0.85, 0.9. The Phase 0 competing-Attention comparator remains evidence, while dedicated-slot production is reversible pending playtests.
