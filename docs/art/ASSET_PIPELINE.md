# Asset pipeline

Prefer code-generated semantic SVG/CSS/Canvas for induction chains, dependency maps, number lines, factor networks, interval nesting, sequence plots, epsilon bands, tangent lines, Riemann partitions, partial sums, and connectors. Static vector assets are limited to logo/icon/resource symbols/chapter seals/achievement/automation/Publication identity. Raster is exceptional.

Pipeline: brief + state matrix → accessible low-fidelity SVG → review at 1440/768/390 and forced colors → source/provenance/license record → optimize without removing title/desc hooks → export deterministic filenames → checksum/visual regression. Canvas requires a synchronized DOM/text/data alternative.

AI-generated material must store exact prompt/tool/date and undergo originality, artifact, license, and accessibility review. Never generate decorative math before mechanics lock. Source files remain editable; exports are reproducible; no binary cache or untracked font license enters the repository.
