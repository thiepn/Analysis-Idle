# Chapter visual language

Shared grammar: paper/surface/ink hierarchy, stable resource shapes and labels, proof nodes with shape + icon + text + state, method cards after Publication, and restrained connective motion.

Natural Numbers: discrete dots/ticks, successor arrows, stepped chains, base/step brackets, warm green accent. Precision uses ruled-square/formal mark; Intuition uses open lens/example mark; never color alone.

Future grammar proposals (not assets): Integers uses directed number-line symmetry; Rationals fraction lattices/density; Reals nested intervals/completeness gaps; Sequences indexed traces; Limits epsilon bands; later chapters define unique mechanics before visual polish.

Locked node states: unavailable (outline + lock label), available (solid outline), selected (double outline + “current”), running (progress value), blocked (warning mark + reason), validated (filled check + text), archived (method-card link). Every visualization has title/description and adjacent structured text/data alternative.
