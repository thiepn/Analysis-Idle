# Effect and multiplier budget

Evaluation order is locked:

1. base quantity/rate;
2. flat additive terms with matching units;
3. one grouped additive percentage per named group;
4. named multiplicative categories, each shown once;
5. formula replacement;
6. exponent change;
7. cap/soft cap.

Natural Numbers allows at most two simple routine activity multipliers (provisional ×1.20 each), one active ceiling, and typed method reuse. Achievements, chapter completion, Publication, locked/unowned content, and hidden ownership grant no multipliers. Exponent changes are absent from player content; `α=0.80` is configuration.

Every effect exposes source ID, activation, target, operation, stacking group, priority, value, cap, reset layer, and display decomposition. Prohibited: dozens of tiny globals, circular conversion, unbounded cost reduction, exponent stacking, effects from locked/unowned content, and rounded UI text that hides a real effect.

Budget gate: a player must explain the dominant contributors from the ledger; computed rate must reproduce exactly from its displayed decomposition within formatting tolerance.
