# Pacing targets

Authoritative event bands are in `docs/design/PROGRESSION_SPEC.md`; all values remain `PROVISIONAL`. Simulator reports distinguish elapsed, active-equivalent, open-tab, and offline credited time.

Key gates: first input ≤15s; passive rate ≤30s; first meaningful decision 1–3m; project 5–10m; automation 20–35m; approach 35–60m; capstone 90–140m; Publication 120–180m. First-session target is 15–25m; campaign 30–50 active-equivalent hours over 4–8 weeks.

While open, visible progress gap ≤30s; useful optimization/decision gap ≤12m after onboarding; system-reveal gap ≤25m before capstone. Forced purchases do not count as decisions. Offline waits may exceed these only when the player saw a plan, ETA, and safe policy.

Reports include purchase frequency, visible reward frequency, meaningful decisions, reveals, automation, transformations, and maximum dead intervals separately.
