# Branch and approach design

## Decision

Natural Numbers uses no permanent branch. It uses reversible per-project approaches (model E), while automation remains universal. Persistent campaign branches are deferred until multiple chapters prove reusable behavior.

| Approach | Fantasy | Behavior | Resource relation | Output | Weakness |
|---|---|---|---|---|---|
| Formal | Build an auditable proof | Exposes obligations; matching obligations become reusable lemmas | Precision-heavy | Lemma artifact | Reveals less downstream context |
| Exploratory | Learn by examples and failure | Reveals examples/counterexamples and hidden requirements before commitment | Intuition-heavy | Requirement/alternative reveal | Fewer reusable formal nodes |
| Constructive | Build the result step by step | Makes Technique preparation visible by decomposing work into explicit steps reusable by structurally similar projects | Balanced | Prepared-step/template artifact | More up-front steps |

Approach requirement vectors are normalized so none is simply fastest. All effects are typed behavioral transformations; any speed modifier is secondary and provisional. Choose freely before start. Mid-project switch retains inputs and ≥90% work (`PROVISIONAL`). No approach disables automation, active accessibility alternatives, or later content.

Constructive is the Technique-facing approach, but Technique is not a permanent player type, stock, hidden proficiency score, or requirement for automation. Formal and Exploratory projects can also contain explicit exercises when mathematically appropriate. All three approaches receive the same universal queue, completion-rule, and reserve capabilities when their global milestones unlock.

Tests compare each approach under balanced, specialized, no-reallocation, and downstream-aware policies. Reject/tune if one is fastest and best downstream, if any creates an unrecoverable trap, or if differences reduce to multipliers.
