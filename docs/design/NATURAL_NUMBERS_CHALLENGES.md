# Natural Numbers challenges

Decision: **DEFERRED until after first Publication and outside the first production pass**. New players should not learn base rules and exception rules together. The `published_foundations` achievement may expose the later challenge-access entry point, but it grants no production power and Phase 1 implements schema extension points only. Phase 2 first slice does not require challenge UI.

Candidate later prototypes:

- **Fixed Allocation:** select one Attention plan before a short dependency set; no reallocation. Teaches forecasting, retains queue-one, grants a badge/alternate archive annotation only.
- **Unknown Requirement:** downstream costs begin hidden but Exploratory artifacts reveal them. Teaches information value; no cost inflation.
- **No Shortcut:** Insight disabled while reusable lemmas/templates remain. Tests automation/planning, not waiting tolerance.

Every challenge must alter a rule, state allowed automation/offline behavior, provide a keyboard/touch-equivalent interaction, avoid mere cost inflation, remain optional, and grant no mandatory power.
