# Product scope

## Initial product

A responsive, local-first static browser game for current desktop and mobile browsers. The browser codebase is canonical. GitHub Pages is the intended static host; the application becomes offline-capable/installable only after PWA lifecycle gates pass.

## Required initial-release capabilities

- deterministic engine and headless simulator;
- progressive chapter campaign with Natural Numbers as the production vertical slice;
- whole Attention, Precision/Intuition, projects, dependencies, universal automation, Insight, offline safe policies, Publication, export/import, accessibility settings;
- finite campaign ending plus optional mastery/replay;
- keyboard/touch/screen-reader parity and accessible mathematics.

## Explicit exclusions

Backend accounts, cloud save, multiplayer, leaderboards, ads, premium currency, daily streaks, seasonal FOMO, native mobile/desktop versions, Steam, localization, mod support, user scripting, and server anti-cheat are rejected for initial v2. Final art/audio, PWA, later chapters, and prestige are outside Phase 1.

## Future extension boundary

Tauri, Capacitor, Steam, supporter editions, and optional cloud synchronization may wrap or synchronize the canonical browser engine. They must not fork simulation logic or make local play dependent on a service.
