# Prestige model

Decision: **DEFERRED UNTIL MULTI-CHAPTER PROTOTYPE**.

Compared timings were after Natural Numbers, Integers, Rational Numbers, Real Numbers, Sequences, the initial campaign, no global prestige, and a framework shift without full reset. Current evidence does not identify a function not already served by Publication, chapter compression, Mastery, optional challenges, approach replay, campaign completion, or New Game Plus.

Phase 1 reserves a nullable, versioned `prestige` extension object and typed reset-layer enum but implements no prestige command, currency, Axiom formula, multiplier, UI, or offline event. A future proposal must name a unique player problem, prove the reset is necessary, define retention/migration/accessibility, compare a non-reset framework shift, and use a multi-chapter simulator/playtest. Real Numbers has no privileged status.
