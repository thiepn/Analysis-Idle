## Strongly supported from available evidence

- **ACCEPTED — clean rewrite:** v1 has a frame-coupled one-resource economy, shallow chapter differentiation, unsafe save boundaries, and a monolithic UI. Preserve it; do not refactor it into v2.
- **ACCEPTED — repository reuse:** history, Pages continuity, and the legacy snapshot remain valuable while v2 lives on isolated branches and new paths.
- **ACCEPTED — progressive disclosure:** both accessibility heuristics and the prototype show that the opening can expose one goal before chapters, achievements, automation, and Publication.
- **ACCEPTED — universal automation:** withholding quality-of-life behind a branch creates a dominant player-type choice.
- **ACCEPTED — engine/UI separation:** legacy frame updates demonstrate why elapsed time and rendering must not be coupled.
- **ACCEPTED — GitHub Pages/local-first browser:** the product needs no backend to prove its core.

## Accepted with revision from prompt-level hypotheses

- **Attention allocation:** use 3→4 whole slots, not an assumed six. Tap/plus-minus and presets replace precision sliders.
- **Resources:** select two primary chapter-local stocks—Precision and Intuition—rather than assuming three. Understanding is non-spendable mastery; Insight is bounded active capacity; Attention is capacity; Mastery is a published record.
- **Branches:** Natural Numbers has reversible project approaches, not permanent branches. Automation is universal.
- **Active play:** stored deterministic Insight targets 10–15% sustained benefit with a 20% ceiling; exact cadence is provisional.
- **Offline:** simulate to an unresolved decision, then follow an explicit safe policy using bounded event-driven stepping.
- **Publication:** a chapter transformation/semantic compression, never a completion multiplier.
- **Frontend:** Preact + TypeScript + Vite, with no framework in engine/content.
- **Numbers:** native number only behind an adapter and range gates.
- **Storage:** a namespaced, validated, rotating localStorage envelope first; IndexedDB is reserved for growth/logs.

## Rejected assumptions

- Six Attention, exponent 0.85/0.90, three resources, Real Numbers prestige, 8h/48h offline windows, and an Axiom formula are not facts.
- Technique is rejected as a primary Natural Numbers resource because its exclusive sink could not be distinguished from project work without added burden.
- Automation as a branch, repeatable production clicking, random active popups, power-bearing achievements, and multiplier-only chapter identity are rejected.
- React is not selected merely for ecosystem size; plain DOM is not selected merely for bundle size.

## Still provisional

Attention exponent 0.80; fourth-slot timing; every project cost/duration; resource caps; Insight cadence/effect; offline credit windows (12h full, 72h maximum credit, 25% tail); first Publication 120–180 active-equivalent minutes; 30–50 hour campaign; approach-switch preservation floor; performance budgets until measured on Phase 1 code.

## Deferred

Global prestige and timing; permanent campaign branches; challenges before first Publication; PWA/service worker; large-number library; IndexedDB canonical saves; audio implementation; localization; later chapter data; postgame.

## Risk of premature implementation

Hard-coding provisional numbers would turn heuristic comparisons into migration debt. Implement only schemas, adapters, typed configuration, deterministic commands, and the Natural Numbers data contract in Phase 1. Human comprehension, fun, and retention remain playtest questions.
