# QA balance gates

The authoritative numerical gates are `docs/balance/BALANCE_GATES.md`. QA additionally requires every gate to link to a reproducible JSON/CSV artifact, configuration/content hashes, policy and stop condition; every failure has severity/owner/disposition; human-only claims (fun, comprehension, frustration) are labeled and supported by playtest protocol rather than simulator scores.

Release blockers: non-finite/reachability failure; universal allocation/approach dominance; dead primary stock; active >20%; plausible opening trap; nondeterministic offline/automation; hidden multiplier; capstone threshold-only; Publication state mismatch; fabricated or stale report.
