# Release checklist draft

- [ ] Accepted phase gates and decision register current; no blocking research/evidence gap.
- [ ] Version/content/save migrations and rollback tested; legacy/export path documented.
- [ ] Deterministic simulator/balance reports reproduce from clean checkout.
- [ ] Browser/AT matrix, keyboard/touch, math, reduced motion, forced colors, zoom/reflow pass.
- [ ] Performance/bundle/save/offline budgets pass on release build.
- [ ] Pages base and protected workflow validated; production backup and owner approval recorded.
- [ ] PWA update/cache gates pass if enabled; otherwise no service worker ships.
- [ ] Asset/audio provenance/licenses complete; no license selected implicitly.
- [ ] Release notes state save boundary, known limitations, provisional content, and recovery/export steps.
- [ ] Production deployment explicitly authorized; `main`/v1 preservation verified before migration.
