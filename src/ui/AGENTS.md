# UI rules

- Support keyboard, touch, focus order/restoration, visible focus, screen readers, reduced motion, high contrast, and mobile portrait.
- Use semantic controls, labels, 44px preferred touch targets, and color-independent meaning.
- Render accessible MathML/HTML or plain language; never expose raw LaTeX.
- Do not rebuild the full application every animation frame or require precision timing/dragging for essential actions.
- Mathematical visualizations need responsive layouts, descriptions, and a textual/data alternative.
